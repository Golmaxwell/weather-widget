# Weather Widget

A lightweight Python weather widget (Weather Desk) that shows current conditions and forecasts for a chosen city.

| `weather-desk-v2.py` | v2 |
| `weather-desk1.py` | v1 |

## Requirements

- Python 3.8 or newer
- Internet connection
- Any libraries imported at the top of the script (install with `pip install <name>`)

## Usage

```bash
python3 weather-desk-v3.4.py
```

## API key

If the app uses a weather API key, store it in a `.env` file. It is excluded from Git by `.gitignore`, so it is never published.
